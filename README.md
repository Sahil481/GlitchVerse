# NEON DEADLINE

**A 2D neon platformer where the world is editable and the ramen is getting cold.**

`Unity 6 (6000.6.6f1)` · `URP 2D` · `C#` · `5 handcrafted levels` · `fully synthesized audio`

</div>

---

## The Pitch

You are **the Courier**. Vex, the ramen king of the Noodle District, has one rule: *the bowl arrives hot, or you don't arrive at all.*

Every level is a delivery run against a countdown. You can't just run faster. You can **glitch the world**: phase through walls, shrink through slots, shift dimensions, flip gravity, and reach into the level to move, re-skin or delete the platforms in your way.

> **Beat the clock. Break the rules of the world.**

## Controls

| Action | Input | Notes |
|---|---|---|
| Move | `A` `D` / arrows | Hold **Sprint** to run faster |
| Jump / double jump | `Space` | Second press in mid-air |
| Dash | Dash key | One air dash per airtime, 1 s cooldown |
| Phase dash | `E` | Pass through pink phase walls, also in mid-air |
| Shrink / grow | Shrink key | Fit through narrow slots |
| Dimension shift | `R` | Ghost platforms become solid; costs energy |
| Manipulate | Left-click an object | Radial wheel: **move**, **material**, **delete** |
| Pause | `Esc` | |

## The Glitch Toolkit

![Mechanics](docs/mechanics.png)

- **Movement**: sprint, double jump and dash chain together. Boost surfaces multiply speed (x1.7), ice slides (x1.35, low grip), mud slows (x0.55) and bouncy surfaces launch higher (x1.5).
- **Phase dash**: a short, fast burst (16 units/s for 0.3 s, 2 s cooldown) that ignores phase walls. Later levels demand it mid-jump.
- **Shrink**: a smaller hitbox for slots and tunnels, usable in the air.
- **Dimension shift**: platforms that exist in the other dimension become solid. Your energy shows as a **ring around the Courier**, only while it matters.
- **Glitch zones**: gravity zones flip you to the ceiling; inversion zones swap left and right.
- **World manipulation**: objects flagged as manipulable can be moved within a range, switched between ICE / MUD / BOOST / BOUNCY, or deleted. Pressure plates and heavy blocks open doors.

## Five Levels, One Escalation

![Levels](docs/levels.png)

| # | Level | Focus | Par | Time limit |
|---|---|---|---|---|
| 1 | First Delivery | Controls tutorial, then sprint, double jump, dash, plate, phase | 1:15 | 2:30 |
| 2 | Slipstream | Environment manipulation: lifts, bridges, deletion, materials | 1:30 | 3:00 |
| 3 | Phantom Lane | Dimension shifts, gravity/inversion zones, shrinking | 1:40 | 3:00 |
| 4 | Inversion | Vertical map with multiple routes and multi-mechanic puzzles | 2:10 | 4:00 |
| 5 | Final Delivery | The gauntlet: every mechanic, ~770 units long | 3:00 | 5:00 |

**Teaching by doing.** Levels 1-3 show hints only for mechanics not yet taught. Level 4 and 5 show none: you've learned everything, so you get full freedom.

**Level 5** is built as eight chapters with mid-air phase dashes, mid-air shrinking, and several platforms you must move, change or delete. A perfect run takes about three minutes; the limit is five.

Level 4 and 5 have several routes, each with its own collectibles. Deep-dive maps of each level are in [`docs/`](docs/) (`map_level1.png` ... `map_level5.png`).

## Scoring

- **Stars:** 3 = all shards and finish under par; 2 = all shards, or finish within 1.45x par; otherwise 1.
- **Score:** time left x 10 + shard bonus + 500 for a no-death run.
- Stars unlock levels; best times are saved per level.

## Making the Clock Hurt

The timer is a gameplay mechanic, so the game is built to make you feel it:

- Battle music loops at 150 BPM, with a panic layer fading in as time runs low.
- A heartbeat, an alarm, countdown numbers and screen-edge pulses in the final seconds.
- The HUD timer pulses and shakes.
- Moving fast has its own feedback: wind streaks, ghost trails, dust, camera pull-back and a looping wind sound.

## Under the Hood

- **Engine:** Unity 6 with the Universal Render Pipeline (2D), neon look from bloom and glow sprites.
- **Data-driven levels:** each level is a JSON file (platforms, phase walls, hazards, zones, plates, doors, shards, checkpoints, tips, start and goal), generated by a script and turned into a scene, so layouts can be tuned quickly.
- **Procedural VFX:** a small effects library (bursts, rings, ghost trails, emitters) draws everything with code, with no hand-authored particle assets.
- **Self-attaching systems:** effects such as dimension, speed and timer pressure attach themselves at runtime, so they work in every scene.
- **Synthesized audio:** all sound effects and music loops are generated by scripts and are tempo-locked for seamless looping.
- **Shared services:** a pooled SFX hub, camera shake/punch/zoom, scene fader and a progress store for stars and best times.

## Run It

1. Install **Unity 6000.6.6f1** (or a close 6000.x) with the 2D / URP modules.
2. Open the project folder in Unity Hub.
3. Open the main menu scene and press **Play**, or use **File > Build Settings** to build for PC.
